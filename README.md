# محاكي توجيه سيارات الإسعاف الذكي 🚑
### Smart Ambulance Pathfinding & Traffic Simulator

مشروع ويب متكامل ومبني باستخدام تقنيات الويب القياسية الخالصة (**Vanilla HTML5, CSS3, ES6 Modules**) بدون أي أطر عمل خارجية (No frameworks / Zero dependencies). يهدف المشروع إلى محاكاة وتوضيح كيفية تنقل سيارات الإسعاف في شبكة شوارع حضرية معقدة تتضمن حوادث وازدحاماً مرورياً، مع تقديم **مقارنة حية وتفاعلية جنباً إلى جنب (Side-by-Side)** بين أشهر خوارزميتين في نظرية المخططات والذكاء الاصطناعي: **خوارزمية Dijkstra** و **خوارزمية A\* Search**.

## ✨ المميزات الرئيسية (Key Features)

1. **مقارنة مرئية مزدوجة متزامنة (Dual Synchronized Grids):**
   - شبكتان متطابقتان بحجم $20 \times 20$ (إجمالي 400 مربع لكل شبكة) تعملان بالتوازي لمقارنة سلوك الخوارزميتين في نفس البيئة والظروف المرورية بدقة.
2. **محرك تحريك متسلسل ذو مرحلتين (Two-Phase Animation Engine):**
   - **المرحلة الأولى:** استعراض متزامن وشعاعي لخطوات فحص واستكشاف العقد (Explored Nodes).
   - **المرحلة الثانية:** إبراز مسار الطوارئ الأقصر والأمثل (Optimal Shortest Path) مع تأثيرات نبض وتوهج بصري.
3. **إعادة التوجيه التفاعلي اللحظي (Live Reactive Rerouting):**
   - بمجرد اكتمال أول محاكاة، يدخل النظام في وضع التوجيه الفوري؛ حيث يؤدي رسم حواجز جديدة أو زيادة الزحام أو سحب سيارة الإسعاف/المستشفى إلى إعادة حساب وعرض المسار الجديد فورياً ($0\text{ ms delay}$) دون أي وميض أو حاجة لإعادة الضغط على زر التشغيل.
4. **أنماط خرائط ذكية مسبقة الإعداد (Map Presets):**
   - **🗺️ خريطة فارغة (Empty City):** أرضية مفتوحة تتيح للمستخدم تصميم سيناريوهات مخصصة بالكامل.
   - **🚦 زحام ساعة الذروة (Rush Hour):** شوارع شريانية رئيسية وتكتلات زحام مروري خانق (تكلفة = 5).
   - **🧩 متاهة المدينة (Maze City):** مبنية بخوارزمية التقسيم التكراري (Recursive Division) مع التحقق الرياضي من وجود مسار متاح.
   - **🎲 عوائق عشوائية (Random Obstacles):** توزيع عشوائي متوازن للجدران والازدحامات المرورية.
5. **لوحة تحكم مبسّطة ومقسّمة إلى 3 خطوات:**
   - **الخطوة (1):** اختيار الخريطة والأداة (جدار، زحام تكلفة 5، مسح الطريق، تحريك الإسعاف، تحريك المستشفى).
   - **الخطوة (2):** اختيار وضع العرض (مقارنة مزدوجة، أو إحدى الخوارزميتين منفردة) وسرعة التحريك (سريع، متوسط، فوري).
   - **الخطوة (3):** زر التشغيل الرئيسي البارز مع أزرار مسح المسار وإعادة ضبط الخريطة بالكامل.
6. **طابع بصري طبيعي وأنيق (Natural Earth-Toned Theme):**
   - لوحة ألوان هادئة ومريحة للعين تجمع بين **الأخضر الزيتوني الملكي (Olive Green)** و**البيج الرملي الدافئ (Warm Beige)** مع خط عربي عصري (**Cairo**) ودعم كامل لاتجاه الكتابة العربي (`dir="rtl"`).
7. **الحماية التامة من الحالات الشاذة (Edge-Case Protection):**
   - منع الكتابة فوق سيارة الإسعاف 🚑 أو المستشفى 🏥 بجدران أو حواجز.
   - إظهار شريط تحذيري أنيق ومتحرك عند انغلاق كافة المنافذ المؤدية للمستشفى (*Route Blocked Warning Banner*).
8. **نافذة شرح الهيكل البرمجي (Architecture Modal):**
   - نافذة منبثقة تفاعلية توضح المقارنة الرياضية بين الخوارزميتين وتشرح بالتفصيل كيفية تطبيق أنماط التصميم البرمجية داخل كود المشروع.

## 🏛️ الهيكل البرمجي وأنماط التصميم (Software Architecture)

تم بناء المشروع باتباع أفضل ممارسات هندسة البرمجيات وتطبيق أنماط التصميم الكلاسيكية (**Design Patterns**) لضمان قابلية الصيانة، التوسّع، وفصل المسؤوليات (**Separation of Concerns**):

```
                               ┌─────────────────────────┐
                               │   controller.js (MVC)   │
                               │   User Events & Input   │
                               └────────────┬────────────┘
                                            │ Calls Mutators
                                            ▼
┌─────────────────────────┐    Registers    ┌─────────────────────────┐
│     mapFactory.js       ├────────────────►│      model.js (MVC)     │
│    (Factory Pattern)    │                 │    (Observer Subject)   │
└─────────────────────────┘                 └────────────┬────────────┘
                                                         │ Emits Events
                                                         ▼
                                            ┌─────────────────────────┐
                                            │      view.js (MVC)      │
                                            │   (Observer Listener)   │
                                            └─────────────────────────┘
```

### 1. نمط النموذج-العرض-المتحكم (Model-View-Controller - MVC):
- **النموذج (`src/model/model.js`):**
  - يمثل مصدر الحقيقة الوحيد (**Single Source of Truth**).
  - يمتلك حالة شبكة الـ $20 \times 20$ ومواقع البداية والنهاية ومصفوفات التكلفة باستخدام حقول خاصة (`#privateFields`).
  - معزول تماماً عن الـ DOM (صفر تعامل مع واجهة المتصفح)، مما يجعله قابلاً للاختبار البرمجي التلقائي في بيئة Node.js.
- **العرض (`src/view/view.js`):**
  - مسؤول حصرياً عن بناء شجرة عناصر الـ DOM للخريطتين وعرض الألوان والتأثيرات الحركية.
  - يحتوي على فئة `AnimationEngine` لإدارة جدولة الإطارات والقدرة على إلغاء التحريك الجاري فوراً عند أي تعديل.
  - يحدّث بطاقات المقاييس اللحظية ويتحكم في شريط النتائج والنافذة المنبثقة.
- **المتحكم (`src/controller/controller.js`):**
  - نقطة الربط وتلقي الأحداث (**Event Delegation**).
  - يستقبل نقرات وسحب الماوس على خلايا الشبكة، وأزرار شريط الأدوات، واختصارات لوحة المفاتيح، واللمس على الهواتف.
  - يترجم تفاعلات المستخدم إلى أوامر مباشرة يوجهها للنموذج (`model.js`).

### 2. نمط المراقب (Observer Pattern):
- يمثل `SimulatorModel` الطرف المُرسِل (**Subject**)، حيث يوفر دالتي `subscribe(observer)` و `notify(eventType, data)`.
- يبث النموذج أحداثاً نمطية مثل:
  - `grid:cellChanged` (عند تعديل خلية).
  - `grid:loaded` (عند استدعاء خريطة جديدة).
  - `position:startMoved` / `position:endMoved` (عند تحريك الإسعاف أو المستشفى).
  - `pathfinding:running` / `pathfinding:done` / `pathfinding:error`.
- يمثل `SimulatorView` الطرف المُستمع (**Observer**)، حيث يشترك في النموذج ويتفاعل تلقائياً مع التحديثات. هذا الفصل هو ما يُمكّن ميزة **إعادة التوجيه اللحظي (Live Rerouting)** بدون أي تشابك معقد بين المتحكم والواجهة.

### 3. نمط المصنع (Factory Pattern):
- تم تطبيقه في الفئة `MapFactory` داخل ملف `src/patterns/mapFactory.js`.
- توفر الفئة واجهة موحدة `MapFactory.createMap(type, rows, cols)` لتوليد الخرائط المختلفة بناءً على الاسم المُمرر.
- تشتمل الفئة على خوارزمية تحقق رياضية باستخدام البحث العرضي (**BFS**) للتأكد من وجود مسار مفتوح بين الإسعاف والمستشفى وضمان عدم انقطاع الاتصال في الخرائط المولدة تلقائياً.

## ⚡ مقارنة الخوارزميات (Algorithms Breakdown)

| وجه المقارنة | خوارزمية Dijkstra | خوارزمية A\* Search |
|---|---|---|
| **نوع البحث** | بحث غير موجه منتظم التكلفة (Uniform-Cost Search) | بحث ارتيادي موجّه بالهدف (Heuristic Search) |
| **دالة التقييم** | $f(n) = g(n)$ (التكلفة الفعلية التراكمية فقط) | $f(n) = g(n) + h(n)$ (التكلفة الفعلية + دالة التقدير) |
| **دالة التوجيه (Heuristic)** | لا توجد ($h(n) = 0$) | مسافة مانهاتن: $h(n) = \|r_1 - r_2\| + \|c_1 - c_2\|$ |
| **سلوك الاستكشاف** | فحص شعاعي دائري يتوسع بالتساوي في جميع الاتجاهات | فحص بيضاوي/مستقيم يندفع مباشرة نحو المستشفى |
| **ضمان المسار الأمثل** | نعم، مضمون دائماً | نعم، لأن مسافة مانهاتن دالة مقبولة ومتسقة (Admissible & Consistent) |
| **عدد المربعات المفحوصة** | كبير جداً (يفحص مناطق خلفية لا علاقة لها بالهدف) | قليل جداً (يوفر عادة ما بين 40% إلى 65% من العقد المفحوصة) |
| **بنية البيانات المستخدمة** | طابور أولويات أصغري (Binary Min-Heap) بتعقيد $O(\log V)$ | طابور أولويات أصغري (Binary Min-Heap) بتعقيد $O(\log V)$ |
| **الاستخدام المثالي** | عند الرغبة في إيجاد أقصر مسار لجميع العقد دفعة واحدة | حالات الطوارئ والإسعاف والتوجيه السريع من نقطة إلى نقطة |

## 🚀 كيفية التشغيل محلياً (How to Run Locally)

المشروع مبني ليعمل مباشرة وبسلاسة تامة دون الحاجة لتثبيت أي مكتبات أو أدوات بناء (Zero dependencies):

### الطريقة الأولى: التشغيل المباشر
- قم بفتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح حديث (Google Chrome, Microsoft Edge, Firefox, Safari).

### الطريقة الثانية: باستخدام خادم محلي (Local Server - اختياري)
إذا كنت تستخدم بيئة تطوير مثل VS Code:
```bash
# باستخدام ملحق Live Server في VS Code
انقر بزر الماوس الأيمن على index.html واختر "Open with Live Server"

# أو باستخدام Node.js npx serve
npx serve .

# أو باستخدام Python
python -m http.server 8000
```
ثم توجه في المتصفح إلى: `http://localhost:8000`.

### تشغيل الاختبارات البرمجية التلقائية:
```bash
node tests/test_suite.mjs
```
