# محاكي توجيه سيارات الإسعاف الذكي 🚑
### Smart Ambulance Pathfinding & Traffic Simulator

تطبيق ويب تفاعلي يحاكي توجيه سيارات الإسعاف داخل المدينة وتفادي الازدحام المروري، مع **مقارنة حية وسريعة** بين خوارزميتي **Dijkstra** و **A* Search** جنبًا إلى جنب، مبني بالكامل بـ **Vanilla JavaScript (ES6 Modules)** بدون أي مكاتب خارجية.

## ✨ المميزات الأساسية

- ⚡ **مقارنة حية مزدوجة:** عرض متزامن لخوارزميتي Dijkstra و A* على شبكتين $20 \times 20$ في نفس اللحظة.
- 🔄 **إعادة التوجيه اللحظي (Live Rerouting):** تحديث فوري للمسار عند رسم عائق أو تحريك الإسعاف/المستشفى دون الحاجة لإعادة الضغط على زر التشغيل.
- 🎨 **رسم تفاعلي على الخريطة:** إمكانية إضافة حواجز (جدران)، مناطق زحام مروري (تكلفة = 5)، أو مسح الطرق.
- 🗺️ **خرائط جاهزة:** تتضمن (خريطة فارغة، زحام ساعة الذروة، متاهة المدينة، وعوائق عشوائية).
- 🌿 **تصميم هادئ وعصري:** واجهة أنيقة بألوان ترابية وزيتونية مريحة للعين، تدعم اللغة العربية بالكامل (`RTL`) وخط **Cairo**.
- 📊 **إحصائيات مباشرة:** مقارنة دقيقة لعدد الخلايا المفحوصة، التكلفة، الخطوات، وزمن التنفيذ بالمللي ثانية.

## ⚡ مقارنة سريعة بين الخوارزميتين

| وجه المقارنة | خوارزمية Dijkstra | خوارزمية A\* Search |
|---|---|---|
| **طريقة البحث** | بحث دائري شامل في كل الاتجاهات | بحث ذكي موجّه مباشرة نحو المستشفى |
| **الدالة الرياضية** | $f(n) = g(n)$ (التكلفة الفعلية) | $f(n) = g(n) + h(n)$ (التكلفة + التقدير بمسافة مانهاتن) |
| **ضمان أقصر مسار** | مضمون دائمًا | مضمون دائمًا |
| **كفاءة الاستكشاف** | تفحص عددًا كبيرًا من العقد | أسرع وتوفر حتى 60% من الخلايا المفحوصة |
| **الاستخدام الأمثل** | إيجاد المسارات لجميع الأهداف | حالات الطوارئ والإسعاف من نقطة إلى نقطة |

## 🏛️ الهيكل البرمجي وأنماط التصميم (Architecture)

تم تنظيم الكود وفق أفضل ممارسات هندسة البرمجيات عبر أنماط التصميم التالية:

- **نمط MVC (Model-View-Controller):**
  - `src/model/model.js`: إدارة بيانات الخريطة وحسابات المسارات (منفصل تمامًا عن الواجهة).
  - `src/view/view.js`: رسم الشبكة وتأثيرات التحريك وعرض الإحصائيات.
  - `src/controller/controller.js`: استقبال نقرات المستخدم وأحداث الفأرة ولوحة المفاتيح.
- **نمط المراقب (Observer Pattern):** يتيح للواجهة (`View`) الاستجابة الفورية والتحديث التلقائي بمجرد تعديل بيانات الخريطة في (`Model`).
- **نمط المصنع (Factory Pattern):** في `src/patterns/mapFactory.js` لتوليد أنماط الخرائط المختلفة والتحقق من فتح مسار صالح بين الإسعاف والمستشفى.

## 🚀 كيفية التشغيل

المشروع لا يحتاج إلى أي تثبيت (No Dependencies):

1. **التشغيل المباشر:** افتح ملف `index.html` في أي متصفح (Chrome, Edge, Firefox).
2. **عبر خادم محلي (اختياري):**
   ```bash
   npx serve .
   ```
3. **لتشغيل الاختبارات التلقائية:**
   ```bash
   node tests/test_suite.mjs
   ```
